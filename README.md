# Traffic-Light Surveillance

## Project Description

Traffic-Light Surveillance is an AI-based traffic monitoring system that uses YOLOv8 and OpenCV to detect vehicles from a traffic video.

## Features

- Vehicle detection
- Vehicle counting
- Traffic activity monitoring
- Low, Medium and Heavy Traffic status
- AI-based object detection

## Technologies Used

- Python
- YOLOv8
- OpenCV
- Google Colab

## Vehicle Classes

The system detects:

- Cars
- Buses
- Trucks
- Motorcycles
